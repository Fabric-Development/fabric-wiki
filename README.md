# Fabric Wiki
[![Built with Starlight](https://astro.badg.es/v2/built-with-starlight/tiny.svg)](https://starlight.astro.build)

This is the source code of wiki pages website for [Fabric](https://github.com/Fabric-Development/fabric).

# Why Astro?

Old wiki pages used mdBook, which was fine since it was a dead simple makrdown based SSG, it worked great till we decided to shake up our visual identity a bit, we realized that mdBook was never designed for anything beyond simple CSS stylesheets and it wasn't that easy to adapt it to look exactly how we wanted.

What pushed us to use Starlight was its ability of using MDX in pair with custom components which was an awesome addition seeing how it could be used to improve the look and feel of Fabric's wiki pages.
